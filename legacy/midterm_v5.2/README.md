# TrustFed-TinyIDS: كود المرحلة الأولى (المراحل 1–4)

نظام كشف تسلل لشبكات IoT يتعلّم الحركة الطبيعية فقط، ويعطي ثلاثة قرارات (NORMAL / UNCERTAIN / ANOMALY)، والعتبات فيه مُعايَرة بطريقة conformal. التصميم الكامل في `../proposal/proposal_v6.md`.

## محتويات المجلد

```
trustids/        الكود المشترك (البيانات، النماذج، القرار الثلاثي، المقاييس، الرسوم)
notebooks/       دفاتر Colab للمراحل 1–4 باللغة التركية، وتُشغَّل بالترتيب 00 ← 04
configs/         edge_iiotset.json: إعدادات مجموعة البيانات الثانية، مسجّلة مسبقًا
tests/           16 اختبار وحدة (11 للقرار الثلاثي + 5 لحسم UNCERTAIN)، ومولّد بيانات اصطناعية
tools/           build_notebooks.py يولّد الدفاتر، و smoke_test.py يشغّلها من البداية للنهاية
local_run_v52/   الدفاتر بعد تشغيلها على بيانات TON_IoT الحقيقية، مع كل النتائج (الإصدار 5.2)
```

دليل باللغة التركية للأستاذ: `README_TR.md`.

## التشغيل على Google Colab

1. **ارفع المجلد إلى Google Drive** في المسار:
   `MyDrive/TrustFed-TinyIDS/`
   يكفي رفع مجلدي `trustids/` و`notebooks/`.
2. **نزّل ملف البيانات** `train_test_network.csv` من صفحة TON_IoT الرسمية (UNSW)، وضعه في:
   `MyDrive/TrustFed-TinyIDS/data/train_test_network.csv`
3. **افتح الدفاتر في Colab بالترتيب** وشغّل كل الخلايا (Runtime → Run all):

   | الدفتر | ماذا يفعل |
   |---|---|
   | `00_setup_and_config` | ينشئ المجلدات وملف الإعدادات، ويتحقق من ملف البيانات |
   | `01_data_preparation` | **المرحلة 1:** التدقيق، وإزالة أعمدة التسرّب، وإزالة التكرار، والتقسيم، والتطبيع |
   | `02_baseline_models` | **المرحلة 2:** Isolation Forest وAutoencoder، مع 10 بذور عشوائية |
   | `03_trust_aware_decision` | **المرحلة 3:** القرار الثلاثي بالعتبتين، واختبار الضمان (E1) |
   | `04_selective_detection_risk_coverage` | **المرحلة 4:** Risk–Coverage، والمقارنات (E2)، والعائلات غير المرئية (E3) |
   | `04b_uncertain_resolution` | **المرحلة 4 (تكملة):** حسم UNCERTAIN بعدّاد لكل جهاز، بميزانية إنذار كاذب أسبوعية، مع خط مرجعي للبوابة |

4. **النتائج** تُحفظ في مجلدات `artifacts/` و`figures/` و`runs/<التاريخ>_midterm_phase4/`. أرسل هذه النتائج للأستاذ في نقطة المراجعة.

**ملاحظات:**
- **وضع الاستكمال:** كل بذرة وكل خطوة تُحفظ في Drive فور انتهائها. إذا انقطعت جلسة Colab افتح الدفتر نفسه وشغّل Run all، فيتخطى ما حُفظ. دليل Colab المفصّل في `COLAB_GUIDE_AR.md`.
- **الإعدادات مسجّلة مسبقًا** في `configs/default.json`: العائلات المخفية، وα وβ، والتقسيم، والبذور. لا تغيّرها بعد رؤية نتائج الاختبار.
- **مدة التشغيل** المتوقعة على Colab المجاني (CPU يكفي): من ساعة إلى ساعتين للدفاتر كلها مع 10 بذور.
- **وضع الاختبار السريع (`TRUSTIDS_QUICK=1`)** مخصص لاختبار الكود فقط، ولا تُستخدم أرقامه في أي تقرير.

## الاختبار محليًا

```bash
python -m pytest tests          # 16 اختبارًا
python tools/smoke_test.py /tmp/trustids_smoke
```

الأمر الأول يشغّل اختبارات الوحدة. الثاني يشغّل الدفاتر كلها على بيانات **اصطناعية**، وأرقامه بلا معنى.
